# النافورة مول — Demo

نسخة تجريبية مقترحة لتحديث موقع [النافورة مول - العقبة](https://www.fountainjo.com/ar).
صفحة واحدة (HTML + CSS + JS) بدون قاعدة بيانات وبدون سيرفر.

## المميزات
- تصميم عربي (RTL) حديث ومتجاوب مع الموبايل
- دليل متاجر مع فلترة حسب الفئة وبحث
- حالة "مفتوح الآن / مغلق" تلقائياً حسب توقيت الأردن
- معرض صور مع تكبير
- خريطة Google وزر الاتجاهات
- نموذج تواصل يرسل الرسالة عبر واتساب (بدون سيرفر)
- زر واتساب عائم وروابط السوشال ميديا

## التعديل
كل البيانات موجودة أعلى الـ `<script>` في `index.html`:
- `STORES` — المتاجر (الاسم، الفئة، الطابق، الشعار)
- `GALLERY` — صور المعرض

## الرفع على GitHub Pages
1. أنشئ Repository جديد (مثلاً `fountain-mall-demo`)
2. ارفع `index.html` و `README.md`
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / root ← Save
4. بعد دقيقة الرابط بيكون: `https://USERNAME.github.io/fountain-mall-demo/`

> الصور والشعارات مأخوذة من الموقع الحالي للمول لأغراض العرض فقط.
